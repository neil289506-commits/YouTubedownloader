☑️  選項 1: 自動化腳本 (推薦 - 5 分鐘)

  1. 確保環境已安裝:
     - Visual Studio 2022 Community
     - CMake 3.20+
     - Qt 6.11.0 MSVC x64

  2. 運行自動化腳本:
     > build_x64_release.bat

  3. 等待編譯完成，運行應用:
     > .\bin\Release\YTDownloader.exe

  優點: 完全自動化，傻瓜式操作
  缺點: 需要自動化腳本支持

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

☑️  選項 2: 手動 CMake 編譯 (詳細 - 10 分鐘)

  1. 設定環境:
     > set QTDIR=C:\Qt\6.11.0\msvc2022_64
     > set PATH=%QTDIR%\bin;%PATH%

  2. 創建構建目錄:
     > mkdir build && cd build

  3. CMake 配置 (強制 x64):
     > cmake .. -G "Visual Studio 17 2022" -A x64

  4. 編譯:
     > cmake --build . --config Release

  5. 運行:
     > .\bin\Release\YTDownloader.exe

  詳見: CMAKE_BUILD_GUIDE.md 或 CMAKE_QUICK_REF.md

☑️  選項 3: qmake 編譯 (簡單 - 3 分鐘)

  1. 環境:
     > set QTDIR=C:\Qt\6.11.0\msvc2022_64
     > set PATH=%QTDIR%\bin;%PATH%

  2. 編譯:
     > qmake YTDownloader.pro -spec win32-msvc
     > nmake

  3. 運行:
     > release\YTDownloader.exe

  詳見: COMPILATION.md
