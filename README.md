# YouTube 下載器 Pro (Qt 版本)

一個功能强大的 YouTube 視頻下載應用，使用 Qt 6.11.0 框架開發。

## 功能特性

### 核心功能
- ✅ **批量下載** - 同時新增多個視頻/播放清單連結
- ✅ **多格式支持** - MP4, MKV, WebM, MP3, MPA
- ✅ **分辨率選擇** - 2160p 到 360p 多檔位
- ✅ **幀率控制** - 20fps 到 60fps
- ✅ **播放清單模式** - 一次下載整個播放清單

### 擴充功能
- ✅ **自動字幕下載** - 支援下載所有語言字幕
- ✅ **自動翻譯** - 將字幕轉換為 SRT 格式
- ✅ **進度顯示** - 實時顯示下載進度
- ✅ **暫停/取消** - 靈活控制下載任務
- ✅ **日誌系統** - 詳細的操作日誌和錯誤追蹤
- ✅ **日誌匯出** - 儲存下載記錄
- ✅ **深色UI主題** - 現代化、舒適的視覺設計
- ✅ **設定保存** - 記住用戶偏好設置
- ✅ **自動依賴** - 自動下載和配置 yt-dlp 和 FFmpeg

## 系統要求

- **OS**: Windows 10/11 (x64)
- **C++ 標準**: C++17
- **編譯器**: MSVC 2022 Community Edition
- **Qt**: 6.11.0 MSVC 2022 版本
- **其他工具**: yt-dlp, FFmpeg (應用程序會自動下載)

## 編譯步驟

### 1. 準備開發環境

```bash
# 確保已安裝
- Visual Studio 2022 Community
- Qt 6.11.0 (MSVC 2022 版本)
```

### 2. 設定 Qt 環境變數

在 Visual Studio Command Prompt 中：

```bash
# 設定 Qt 路徑
set QTDIR=C:\Qt\6.11.0\msvc2022_64
set PATH=%QTDIR%\bin;%PATH%
```

### 3. 編譯

使用 Qt Creator：

```
1. 開啟 YTDownloader.pro
2. 選擇 MSVC 2022 工具鏈
3. 設定 Release/Debug 構建模式
4. 點擊「Build」
```

或使用命令列：

```bash
# 在項目目錄執行
qmake YTDownloader.pro -spec win32-msvc
nmake
```

### 4. 運行

```bash
# 在 build 目錄找到可執行文件
./YTDownloader.exe
```

## 依賴項

應用程序會在首次運行時自動下載：

- **yt-dlp** - YouTube 下載核心
  - GitHub: https://github.com/yt-dlp/yt-dlp
  - 自動下載位置: `./yt-dlp.exe`

- **FFmpeg 6.0** - 多媒體處理
  - GitHub: https://github.com/GyanD/codexffmpeg
  - 自動下載位置: `./ffmpeg.exe`, `./ffprobe.exe`

## 使用方法

### 基本流程

1. **新增連結**
   - 在「連結」欄位輸入 YouTube URL
   - 點擊「➕ 新增」按鈕
   - 連結會出現在列表中，並預設勾選

2. **設定下載選項**
   - **格式**: 選擇輸出格式（MP4、MKV 等）
   - **解析度**: 選擇視頻品質（最高 2160p）
   - **幀率**: 選擇幀率（最高 60fps）
   - **播放清單**: 勾選以下載整個播放清單
   - **字幕**: 勾選以下載所有可用字幕
   - **翻譯**: 勾選以轉換字幕格式

3. **選擇下載位置**
   - 點擊「📁 瀏覽」選擇保存目錄
   - 或直接編輯路徑欄位

4. **開始下載**
   - 確認要下載的項目已勾選
   - 點擊「▶️ 開始下載」
   - 在日誌區域追蹤進度

### 進階控制

- **暫停**: 點擊「⏸ 暫停」暫停當前下載
- **取消**: 點擊「⏹ 取消」中止所有下載任務
- **移除**: 勾選要移除的項目，點擊「🗑️ 移除」
- **清除日誌**: 清空下載日誌記錄

## 常見問題

### Q: 首次運行時很慢？
A: 應用程序正在下載 yt-dlp (~40MB) 和 FFmpeg (~180MB)。只需一次。

### Q: 如何代理下載？
A: 此版本不支援代理。yt-dlp 會使用系統代理設置。

### Q: 能否同時下載多個？
A: 當前設計為順序下載以避免速率限制。多線程版本開發中。

### Q: 如何更新 yt-dlp？
A: 刪除 `yt-dlp.exe` 文件，重新運行應用程序。
